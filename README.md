# Alleyne Automotive

Initial production website build for Alleyne Automotive.

## Current scope

- Responsive black / metallic-gold design based on the approved concept\n- True SVG logo and SVG favicon\n- High-resolution automotive photography sourced from Unsplash
- Homepage hero with "Vehicle Sourcing" / "Any make. Any model."
- Sourcing process and recently sourced sections
- Dedicated enquiry page with responsive form
- Mobile navigation
- Static, dependency-free HTML/CSS/JS

## Intentionally not included yet

- Headlight / windscreen animations
- Live enquiry delivery or email integration
- Hosting / deployment configuration
- Production contact details

No deployment has been configured from this repository.
