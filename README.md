# Alleyne Automotive

Production website build for Alleyne Automotive.

## Current design

- Customer's official AA/car artwork preserved in a dedicated transparent header mark
- Cache-busted 512×512 favicon built from the same official mark
- Full-resolution generated black BMW PNG hero in a dark gold-lit garage
- No artificial dark panel or gradient behind the homepage hero copy
- Vehicle sourcing process: Find → Source → You choose
- "From your first car to your dream car" positioning
- Full-resolution Fiat 500 / Golf Mk8 / Audi RS6 category imagery
- Dedicated responsive enquiry page
- Mobile navigation
- No headlight or windscreen animations yet

## Asset quality

The BMW, Fiat 500, Golf Mk8 and Audi RS6 use the original high-resolution PNG outputs with no lossy WebP compression.

## Deployment

This commit changes the GitHub repository only. No Cloudflare deployment action is performed by ChatGPT.
